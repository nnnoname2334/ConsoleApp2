# Практическая работа №2. Консольный клиент для JSONPlaceholder

Консольное приложение на C# для работы со списком задач пользователей через REST API сервиса [JSONPlaceholder](https://jsonplaceholder.typicode.com).

## Описание

Программа отправляет HTTP-запросы к API, получает ответы в формате JSON, преобразует их в объекты `Todo` и позволяет:

- просматривать задачи конкретного пользователя;
- находить задачу по её ID;
- создавать новую задачу;
- изменять статус задачи;
- удалять задачу.

> JSONPlaceholder только имитирует изменение данных. Запросы `POST`, `PATCH` и `DELETE` возвращают корректные ответы, но на сервере изменения фактически не сохраняются.

## Технологии

- C#, .NET Framework 4.7.2
- `HttpClient` для отправки запросов
- `System.Net.Http.Json` для работы с JSON (NuGet-пакет)
- `async/await` для сетевых запросов

## Требования

- Visual Studio 2022
- .NET Framework 4.7.2
- NuGet-пакет **System.Net.Http.Json** (подтягивает `System.Text.Json`)
- Подключение к интернету

## Запуск

1. Создать проект «Консольное приложение (.NET Framework)» с версией 4.7.2.
2. Установить через «Управление пакетами NuGet» пакет `System.Net.Http.Json`.
3. Заменить содержимое `Program.cs` кодом из этого репозитория.
4. Запустить проект (F5 или Ctrl+F5).

## Используемые endpoints

| Метод  | Адрес                | Назначение                       |
|--------|----------------------|----------------------------------|
| GET    | `/todos?userId={id}` | Получить все задачи пользователя |
| GET    | `/todos/{id}`        | Получить одну задачу по ID       |
| POST   | `/todos`             | Создать новую задачу             |
| PATCH  | `/todos/{id}`        | Изменить статус задачи           |
| DELETE | `/todos/{id}`        | Удалить задачу                   |

Базовый адрес: `https://jsonplaceholder.typicode.com`

## Структура кода

- **`Todo`** — модель задачи: `UserId`, `Id`, `Title`, `Completed`.
- **`TodoService`** — класс с методами для каждого запроса к API: `GetByUserAsync`, `GetByIdAsync`, `CreateAsync`, `UpdateStatusAsync`, `DeleteAsync`.
- **`Program`** — меню, ввод данных пользователем и вывод результатов.

## Обработка ошибок

- Неуспешные HTTP-ответы обрабатываются через `EnsureSuccessStatusCode`, пользователю выводится сообщение об ошибке.
- Если задача по ID не найдена (код 404), выводится сообщение «Задача не найдена».
- Перехватываются превышение времени ожидания и ошибки разбора JSON.
- Ввод пользователя проверяется: ID должен быть положительным числом, название задачи не может быть пустым.

## Пример вывода

```
Введите ID пользователя: 1
ID: 1 | delectus aut autem | не выполнена
ID: 2 | quis ut nam facilis et officia qui | не выполнена
```

Латинские названия задач — это тестовые данные (lorem ipsum), которые отдаёт сервер JSONPlaceholder.
